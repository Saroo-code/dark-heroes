# 🖤 DARK HEROES

> Enter the Darkness.

DARK HEROES is a dark-themed, multi-page web development project featuring powerful fictional heroes, stories, abilities, a gallery, and an interactive battle game.

## ⚔️ Features

- 🦸 20 unique heroes
- 👤 Individual hero profile pages
- ⚡ Powers and abilities section
- 📖 Hero stories
- 🖼️ Dark-themed image gallery
- 🎮 Interactive hero battle game
- 📱 Responsive multi-page design
- 🌑 Dark animation and visual effects
- 🔥 Red glow and atmospheric background effects
- 🧭 Multi-page navigation

## 🦸 Heroes

The project includes 20 heroes:

1. Shadow Reign
2. Void Walker
3. Nightfall
4. Crimson Wraith
5. Frostbane
6. Thunder Veil
7. Soul Hunter
8. Ember Knight
9. Iron Phantom
10. Dreadfang
11. Raven Hex
12. Bloodmoon
13. Ash Reaper
14. Gravity Lord
15. Dark Nova
16. Silent Blade
17. Storm Reaper
18. Mist Walker
19. Hellforged
20. Eclipse

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Git & GitHub
